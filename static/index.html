The Team
9 Agents. One Goal.

Each agent is specialized, self-validating, and can retry or escalate failures autonomously.

🧠
Orchestrator Agent
Master controller. Plans tasks, dispatches agents in order, tracks state, and re-routes on QA failure.
IN: topic, duration OUT: task manifest re-routes on fail
✍️
Script Agent
LLM-powered writer. Generates structured scene-by-scene script with narration, cues, and timing data.
IN: topic + style OUT: script JSON self-refine ×3
🎬
Storyboard Agent
Maps every script scene to image prompts, camera motions, and transition specs for the animation pipeline.
IN: script JSON OUT: frame prompts OUT: motions
🎨
Animation Agent
Renders 2D animated scene clips via diffusion + vector pipeline. Detects artifacts and re-renders bad frames.
IN: frame prompts OUT: scene MP4s fallback: static
🎙️
Voice & Audio Agent
TTS voiceover + AI music composition + SFX. Returns word-level timestamps for subtitle sync.
IN: narration text OUT: voiceover MP3 OUT: timestamps
✂️
Editor Agent
Stitches clips, mixes audio tracks, burns subtitles, applies transitions, and colour-grades the final cut.
IN: clips + audio OUT: final MP4 OUT: SRT file
🔍
QA Agent
5-dimension quality gatekeeper: visual, audio, subtitles, fidelity, and policy. Routes failures back to source agent.
IN: final video OUT: QA report loop ×2 max
📊
SEO Agent
Generates A/B title variants, keyword-rich description, 30 tags, and thumbnail — all scored by predicted CTR.
IN: script + topic OUT: metadata OUT: thumbnail
📤
Publisher Agent
Uploads via YouTube Data API v3, schedules at peak audience hours, retries on failure, saves to draft if needed.
IN: video + metadata OUT: YouTube URL retry ×3
